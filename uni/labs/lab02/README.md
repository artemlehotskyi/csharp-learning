## Завдання 1. Знак числа

Ввести одне ціле число.

Якщо число більше нуля — вивести `POSITIVE`.
Якщо число менше нуля — вивести `NEGATIVE`.
Якщо число дорівнює нулю — вивести `ZERO`.

## Завдання 2. Високосний рік

Ввести ціле число `year`, яке позначає рік. Значення `year` повинно бути не меншим за 1.

Рік вважається високосним, якщо він ділиться на 4, але не ділиться на 100, або ділиться на 400.

Якщо рік високосний — вивести `LEAP`.
Інакше — вивести `NOT_LEAP`.

Приклади:

`2000 → LEAP`

`1900 → NOT_LEAP`

`2024 → LEAP`

`2023 → NOT_LEAP`

## Завдання 3. Податок на дохід

Ввести невід’ємне дійсне число `income`, яке позначає річний дохід.

Весь дохід оподатковується однією ставкою відповідного діапазону:

- `0 ≤ income < 10000` → `0`
- `10000 ≤ income < 50000` → `income * 0.10`
- `50000 ≤ income < 100000` → `income * 0.20`
- `income ≥ 100000` → `income * 0.30`

Обчислити та вивести суму податку.

Для автоматичної перевірки десятковим роздільником у вхідних даних використовується крапка (`.`).

Приклад:

`25000 → 2500`

## Завдання 4. Голосна чи приголосна

Ввести один символ — латинську літеру.

Регістр літери не враховується.

Голосними вважаються літери `A`, `E`, `I`, `O`, `U`.
Усі інші латинські літери вважаються приголосними. Літера `Y` є приголосною.

Якщо літера голосна — вивести `VOWEL`.
Інакше — вивести `CONSONANT`.

## Завдання 5. Сторони трикутника

Ввести три дійсні числа `a`, `b` та `c`.

Значення вважаються сторонами трикутника, якщо всі вони додатні та виконується нерівність трикутника:

- `a + b > c`;
- `a + c > b`;
- `b + c > a`.

Якщо всі умови виконуються — вивести `VALID`.
Інакше — вивести `INVALID`.

Для автоматичної перевірки десятковим роздільником у вхідних даних використовується крапка (`.`).

Приклади:

`3, 4, 5 → VALID`

`1, 2, 3 → INVALID`

`5, 1, 1 → INVALID`

## Завдання 6. Найдовша сторона

Ввести три додатні дійсні числа `a`, `b` та `c` — довжини сторін. Перевіряти нерівність трикутника не потрібно.

Визначити, яка сторона є найдовшою.

Якщо найдовшою є сторона `a` — вивести `a`.
Якщо найдовшою є сторона `b` — вивести `b`.
Якщо найдовшою є сторона `c` — вивести `c`.
Якщо дві або три сторони мають однакову найбільшу довжину — вивести `TIE`.

Для автоматичної перевірки десятковим роздільником у вхідних даних використовується крапка (`.`).

Приклади:

`3, 4, 5 → c`

`5, 5, 3 → TIE`

## Завдання 7. Сума чисел від 1 до n

Ввести додатне ціле число `n`.

Обчислити суму всіх цілих чисел від 1 до `n` включно з використанням циклу та вивести результат.

Приклад:

Для `n = 100`:

`1 + 2 + ... + 100 = 5050`

Результат:

```text
5050
```

## Завдання 8. Таблиця множення

Ввести ціле число `n`.

Вивести добутки числа `n` на числа від 1 до 10 включно.

Кожен добуток вивести з нового рядка.

Приклад:

Для `n = 5`:

Вхідні дані:

```text
5
```

Результат:

```text
5
10
15
20
25
30
35
40
45
50
```

## Завдання 9. Факторіал

Ввести ціле число `n`. Значення `n` задовольняє умову `0 ≤ n ≤ 20`.

Обчислити факторіал `n!` з використанням циклу та вивести результат.

`0!` дорівнює `1`.

Приклад:

Для `n = 5`:

`1 * 2 * 3 * 4 * 5 = 120`

Результат:

```text
120
```

Знайти суму всіх простих чисел від 1 до `n` включно та вивести результат.

Число 1 не є простим.

Приклад:

Для `n = 50`:

Результат:

```text

```

## Завдання 11. Числа Фібоначчі

Ввести додатне ціле число `limit`.

Розглянути числа Фібоначчі, менші за `limit`. Перші два числа послідовності дорівнюють `1` і `1`.

Обчислити суму таких чисел та їх кількість.

Вивести спочатку суму, а потім кількість.

Приклад:

Для `limit = 10` числа Фібоначчі `1, 1, 2, 3, 5, 8`:

Вхідні дані:

```text
10
```

Результат:

```text
20
6
```

## Завдання 12. Найбільший спільний дільник

Ввести два додатні цілі числа.

Знайти їх найбільший спільний дільник (НСД) та вивести результат.

Приклад:

Вхідні дані:

```text
48
18
```

Результат:

```text
6
```
