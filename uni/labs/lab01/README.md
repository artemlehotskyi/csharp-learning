# Практична робота №1
## Лінійні алгоритми та розгалуження

Практична робота складається з 8 незалежних завдань.

Кожне завдання необхідно реалізувати у відповідному проєкті:

- Завдання 1 → `task01`
- Завдання 2 → `task02`
- Завдання 3 → `task03`
- Завдання 4 → `task04`
- Завдання 5 → `task05`
- Завдання 6 → `task06`
- Завдання 7 → `task07`
- Завдання 8 → `task08`

## Завдання 1. Перевірка дня та місяця

Ввести два цілі числа `day` та `month` і перевірити, чи можуть вони бути днем та місяцем.

Значення вважаються коректними, якщо:

- `day` знаходиться в діапазоні від 1 до 31 включно;
- `month` знаходиться в діапазоні від 1 до 12 включно.

Якщо обидва значення коректні — вивести `VALID`.
Інакше — вивести `INVALID`.

## Завдання 2. Сума перших двох цифр дробової частини

Ввести додатне дійсне число, яке містить щонайменше дві цифри після десяткового роздільника.

Отримати перші дві цифри після десяткового роздільника та вивести їх суму.

Для автоматичної перевірки десятковим роздільником у вхідних даних використовується крапка (`.`).

Приклад:

`3.456 → 9`

## Завдання 3. Привітання залежно від часу доби

Ввести ціле число `h`, що відображає годину доби. Значення `h` повинно знаходитися в діапазоні від 0 до 23 включно.

Залежно від часу доби вивести відповідне привітання:

- `0 ≤ h < 6` → `Доброї ночі!`
- `6 ≤ h < 12` → `Доброго ранку!`
- `12 ≤ h < 18` → `Добрий день!`
- `18 ≤ h < 24` → `Добрий вечір!`

## Завдання 4. Максимальне та мінімальне значення

Ввести три цілі числа.

Вивести спочатку максимальне, а потім мінімальне значення.

Приклад:

Вхідні дані:

```text
7
-2
4
```

Результат:

```text
7
-2
```

## Завдання 5. Площа прямокутника

Створити програму, яка обчислює площу прямокутника з використанням дійсних чисел типу `double`.

Користувач має ввести довжину та ширину прямокутника.

Обчислити та вивести площу прямокутника.

## Завдання 6. Перевірка числа на парність

Ввести ціле число.

Якщо число парне — вивести `EVEN`.
Інакше — вивести `ODD`.

## Завдання 7. Перетворення температури

Ввести температуру `C` у градусах Цельсія.

Перетворити її у градуси Фаренгейта за формулою:

`F = C * 9 / 5 + 32`

Вивести отримане значення.

## Завдання 8. Сума натуральних чисел

Ввести додатне ціле число `n`.

Обчислити суму перших `n` натуральних чисел без використання циклів та вивести результат.

Приклад:

Для `n = 5`:

`1 + 2 + 3 + 4 + 5 = 15`

Результат:

```text
15
```
